# Harkirat Singh Bootcamp 1.0 — Advanced Assignments

A personal practice repository for the **advanced assignments** from [Harkirat Singh's Bootcamp 1.0](https://harkirat.classx.co.in/). Each project here is built to reinforce real-world full-stack and DevOps skills covered in the bootcamp curriculum.

---

## Purpose

This repo serves as a hands-on workspace to:

- Practice and implement advanced concepts taught in Bootcamp 1.0
- Build production-grade projects covering web development and DevOps
- Maintain a structured record of progress through the bootcamp assignments

---

## Repository Structure

```
harkirat-bootcamp-1.0/
└── webdev-devops/               # Web Development & DevOps assignments
    ├── contest-platform/        # Contest/quiz platform backend
    ├── course-selling-api/      # REST API for a course-selling application
    ├── hotel-management/        # Hotel management system
    └── super30-appointment-booking/  # Appointment booking system
```

---

## Projects Overview

### [`webdev-devops/`](./webdev-devops)

Contains backend and full-stack projects focused on Node.js, REST APIs, databases, and DevOps practices.

| Project                       | Description                                                                    |
| ----------------------------- | ------------------------------------------------------------------------------ |
| `contest-platform`            | A platform to host and manage coding contests with proper API response formats |
| `course-selling-api`          | RESTful API for managing and selling online courses                            |
| `hotel-management`            | Backend system for hotel bookings and management                               |
| `super30-appointment-booking` | Appointment scheduling and booking system                                      |

---

## Tech Stack

- **Runtime**: Node.js
- **Language**: TypeScript / JavaScript
- **Frameworks**: Express.js
- **Databases**: PostgreSQL, MongoDB
- **Tools**: Prisma, Zod, JWT, REST APIs

---

## Getting Started

Each project has its own setup. Navigate into any project folder and follow its local `README.md` for specific instructions.

```bash
# Example
cd webdev-devops/course-selling-api
npm install
npm run dev
```
